# BarnBoss Project №5
A console application implementing an object-oriented farm management simulation game.
The system supports multiple users who manage their own farm and interact in a shared economic environment. Players can produce products, trade on a shared market, and complete tasks posted on a shared board.
Each player has their own warehouse to store products and manages their resources to increase their available cash and points, which are used to rank players.
### Purpose of this version of BarnBoss
___
Project for Introduction to Programming Practicum course at Faculty of Mathematics and Informatics, Sofia University.
